# AWS Retail Sales ETL Pipeline

A cloud-based retail sales ETL pipeline using Python, Pandas, Amazon S3, AWS Lambda, AWS IAM, AWS Glue Database, and Amazon CloudWatch.

## Project Overview

This project demonstrates an end-to-end retail sales ETL pipeline. Raw sales data is ingested, cleaned and transformed using Python and Pandas, and the resulting processed and curated data is stored in different Amazon S3 layers.

## ETL Pipeline Architecture

```text
Raw Sales Data
      ↓
Amazon S3 — Raw Layer
      ↓
AWS Lambda — S3 Event Trigger
      ↓
Python ETL Processing
      ↓
Amazon S3 — Processed Layer
      ↓
Amazon S3 — Curated Layer
      ↓
Analytics-Ready Data
```

## AWS Services Used

* Amazon S3 — Cloud data storage
* AWS Lambda — Event-driven S3 trigger
* AWS IAM — Access and role management

## S3 Data Layers

### Raw Layer

Stores the original retail sales data before processing.

File: `sales.csv`

### Processed Layer

Stores cleaned sales data generated by the ETL process.

File: `cleaned_sales.csv`

### Curated Layer

Stores analytics-ready category-wise sales summaries.

File: `curated_sales_summary.csv`

### Scripts Layer

Stores the Python ETL processing script.

File: `etl_process.py`

### Logs Layer

Stores ETL execution logs.

File: `etl_execution.log`

## ETL Process

1. Read raw sales data from CSV.
2. Remove duplicate records.
3. Remove completely empty rows.
4. Generate cleaned sales data.
5. Filter completed orders.
6. Calculate total sales amount.
7. Generate category-wise sales summary.
8. Generate ETL execution logs.

## AWS Lambda Integration

An S3 event trigger invokes the Lambda function when a new file is uploaded to the `raw/` folder.

The Lambda function receives the S3 event and records the event information in Amazon CloudWatch.
